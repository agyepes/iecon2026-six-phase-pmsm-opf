Current configuration:
- Publishing source: main branch, repository root (/).
- The empty .nojekyll file keeps the existing HTML, JavaScript, data and documents as static files.
- HTTPS is enabled. The viewer runs entirely in the visitor's browser; no download, account or MATLAB installation is required.

To maintain the collection:
1. Keep earlier releases unchanged. Add later resources in new documented release folders.
2. Update viewer/index.html only when a new version should become the default online viewer.
3. Update the homepage resource links and collection metadata, keeping the OPF paper [25] as the viewer's primary association.
4. Rebuild manifests, checksum lists and download archives after changing their contents.
5. Commit changes to main. Check the Pages deployment and verify the homepage, short /viewer/ address, operating-point calculation and downloads on the published site.
6. Create a matching tagged release with the verified archive and checksum files.
