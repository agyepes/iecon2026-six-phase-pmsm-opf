# Citation information

This supplementary package is associated primarily with the **IEEE IECON 2026 open-phase-fault paper [25]**. Use the paper citation below and identify the package as **Interactive supplementary material for the IEEE IECON 2026 open-phase-fault paper, version 1.0.0 (6 October 2026)**.

No DOI has been assigned to this supplementary package. The DOIs below identify the author preprints on arXiv.

## Reproducibility

Record the package version and HTML checksum from [manifest.json](manifest.json) when reporting exported results. Preserve the exported operating point, method, constraint status, and stated allowance. Cite the supporting method papers when discussing NSBE-FRML or Atallah; their complete references are in the viewer.

[CITATION.cff](CITATION.cff) provides machine-readable metadata. Its preferred-citation DOI belongs to [25]'s author preprint, not to this software package. Package version 1.0.0 is separate from the HTML's retained internal model identifier.
